# 🤖 Antigravity & Claude Code Hamkorlik Yo'riqnomasi

Ushbu tizim sizga **Google Gemini (Antigravity)** va **Anthropic Claude Code** ni bitta loyiha ustida ayni bir vaqtda "juftlikda dasturlash" (Pair Programming & Peer Review) rejimida ishlatish imkonini beradi.

## 🚀 Qanday Foydalaniladi?

### 1-Qadam: Claude Code terminalini oching
Loyihangiz papkasida (`c:\Users\user\Desktop\Antigravity\Power Point`) alohida terminal oynasida Claude Code'ni ishga tushiring:
```powershell
claude
```
Chunki biz loyiha ildiziga [`CLAUDE.md`](../CLAUDE.md) faylini joylashtirdik, Claude Code ochilishi bilanoq Antigravity bilan hamkorlikda ishlayotganini va loyiha qoidalarini darhol anglab yetadi!

### 2-Qadam: Claude Code'ga savol yoki topshiriq bering
Masalan, Claude Code terminaliga quyidagicha yozing:
> *"Loyihani skaner qil va `.collab/COUNCIL.md` dagi Antigravity so'ragan masalalar bo'yicha o'z tahliling va tavsiyalaringni yozib qoldir."*

### 3-Qadam: Antigravity (bu yerda) ga xabar bering
Menga shunchaki:
> *"Claude Code o'z fikrlarini `.collab/COUNCIL.md` ga yozdi, o'qib chiq va yechim ber"* deb ayting.

Men darhol uning tahlillarini o'rganib chiqaman, kerakli takliflarni tasdiqlayman va kodni to'g'rilab, natijasini yana o'sha faylga va sizga taqdim etaman!
